# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## The short version

Be kind and constructive. This is a small, low-stakes project — a dashboard for looking at pull requests. Treat everyone with respect regardless of experience, identity, or background.

**Encouraged:** helpful feedback, patience with newcomers, assuming good faith, keeping discussion on the work.

**Not okay:** harassment, personal attacks, discriminatory language, or trolling.

## Reporting

If someone's behavior is a problem, contact the maintainer privately by opening a GitHub issue or reaching out to [@alberthammerich](https://github.com/alberthammerich). Reports are handled discreetly, and maintainers may edit, hide, or remove contributions and comments that violate this code.
